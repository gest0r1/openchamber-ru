# Notifications

Notifications tell you when something needs your attention so you don't have to watch the screen — a session finished, hit an error, asked a question, or needs permission to do something. Set them up at **Settings → OpenChamber → Notifications**.

## Turn them on

1. Open **Settings → OpenChamber → Notifications**.
2. Allow notifications when your browser or system asks.
3. Choose what you want to be told about:
   - a session **finishes**
   - a session hits an **error**
   - a session **asks a question**
   - a session needs **permission**
   - **subtasks** complete

## How they reach you

- on **desktop**, you get native system notifications
- in a **browser or installed app**, you get web push notifications, so they arrive even when the tab is in the background
- in the **iPhone and Android apps**, you get push notifications. What they say is encrypted between your server and your phone, so the push services on the way see only a generic title. On your phone each one shows the session name and what happened: the agent's reply, its question, or the command it wants to run

Sessions set to auto-accept won't nag you with permission notifications.

## Telegram

Open **Settings → OpenChamber → Notifications → Telegram** to add your
Telegram bot token and the chats where OpenChamber should send messages.
Recipients can be private chats, groups or a specific topic with a thread ID.
Choose a default recipient and use **Test** to confirm that the bot can
send to that chat.

Automatic Telegram alerts are off for every session until you explicitly
enable them. You can ask a managed agent to enable Telegram notifications
for its current session, or use the session subscription API. An agent can
also send an explicit message or Markdown file to any configured recipient
without first subscribing the session.

Markdown files are sent as attachments by default so you receive the
original `.md` document. The `formatted` mode sends Telegram HTML text.
The file must be located in the calling session's working directory and
must be no larger than 10 MB.

Telegram receives brief event notifications and optional session links.
The app does not send your chat transcript as part of automatic alerts.

## Customize the wording

Each kind of notification has a title and message template you can edit, using fields like the agent name and model. There's also a limit on how much of the last message is included, so notifications stay short.
