# Installeren

U kunt OpenChamber op drie manieren gebruiken:

- als desktopapp voor macOS
- als webapp via de CLI, ook te installeren als app op uw telefoon via een PWA
- als VS Code-extensie

## Vooraf

Installeer eerst [OpenCode](https://opencode.ai). OpenChamber bouwt daarop voort.

## Web en PWA

```bash
version=$(curl -fsSL https://api.github.com/repos/gest0r1/openchamber-ru/releases/latest | sed -nE 's/.*"tag_name": *"v([^"]+)".*/\1/p')
npm install -g "https://github.com/gest0r1/openchamber-ru/releases/download/v$version/openchamber-web-$version.tgz"
openchamber --ui-password be-creative-here
```

Open de URL die de CLI toont, meestal `http://localhost:3000`. U ziet nu de sessielijst van OpenChamber. Via de optie 'Installeren' in de adresbalk van uw browser kunt u de webapp als app toevoegen.

## Desktop

Download de nieuwste desktopversie via de GitHub-releases of de downloadpagina van OpenChamber. Open de app en meld u aan zoals u gewend bent voor OpenCode.

## VS Code

Installeer de extensie via de VS Code Marketplace en meld u aan zoals u gewend bent voor OpenCode. De OpenChamber-weergave verschijnt vervolgens in de zijbalk.
